# Tahir Russell – Media & Communications

One-page portfolio site for Tahir Russell, media producer and digital marketing strategist.

Plain HTML, CSS and JavaScript with no build step. Open `index.html` in a browser, or serve the folder with any static host such as GitHub Pages.

| File | What it is |
|---|---|
| `index.html` | The homepage |
| `styles.css` | Colors for light and dark themes, fonts, layout |
| `script.js` | Light/dark toggle (remembered per visitor) and the footer year |
| `fonts.html` | Test page comparing heading/body font pairings |
| `stats.html` | Test page comparing animated designs for the stats strip |
| `headshot.jpg` | Hero photo, cropped square (480×480) for the circular frame |

## Changing the font

The three `--head-…`/`--body-font` lines at the top of `styles.css` set the type. `fonts.html` shows each option with the exact lines to paste. Update the Google Fonts `<link>` in `index.html` to match.
